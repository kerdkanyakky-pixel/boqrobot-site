ตั้งสเกล วัดพื้นที่ ความยาว นับจุดบนแบบ PDF ได้ BOQ เป็น Excel ยอดเป็นสูตร แก้ต่อได้
โหลดโปรแกรม (Windows 10/11) — ทดลองใช้ฟรี 3 เดือน

ดาวน์โหลด BOQ Robot ไฟล์ประมาณ 34 MB

  1. คลิกขวาไฟล์ที่โหลดมา → Extract All (แตกไฟล์)
  2. ในโฟลเดอร์ที่แตกออกมา ดับเบิลคลิก Install_BOQRobot.bat — ถ้า Windows ขึ้นกล่องสีฟ้า ให้กด More info → Run anyway
  3. รอประมาณ 1 นาที ไอคอน BOQ Robot จะขึ้นบนหน้าจอ

หลังทดลอง 3 เดือน กดปุ่ม 🔑 สิทธิ์ใช้งาน ในโปรแกรม แล้วส่งรหัสเครื่องมาที่ไลน์ 099-998-9222 เพื่อรับรหัสเปิดใช้
